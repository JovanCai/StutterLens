游戏自身卡顿（多为着色器编译）

卡顿时系统层面没有发现异常，问题大概率在游戏内部。最常见的是首次出现某种画面效果时的着色器编译。本次有 2 次轻微顿挫和它有关，判断把握低。依据：系统层面无异常，游戏此时在大量读盘，较可能在加载新场景。

处理建议
  1. 简单重复游玩同一场景，编译卡顿会逐渐减少。
  2. 简单更新游戏。刚更新显卡驱动后着色器会重新编译，前几局卡顿属正常。
  3. 中等在显卡控制面板中把着色器缓存大小设为 10GB 或无限制。
  4. 进阶游戏支持切换 DX11、DX12 或 Vulkan 的话，可以换一个对比。

显卡驱动延迟过高

这个驱动处理硬件中断（DPC/ISR）耗时过长，占住了 CPU 核心，游戏线程只能排队等待。本次有 1 次轻微顿挫和它有关，判断把握低。依据：卡顿时显卡驱动在单个核心上的中断处理耗时明显偏长。

处理建议
  1. 简单从官网下载最新驱动，安装时选择清洁安装。
  2. 简单关闭显卡软件的游戏内叠加层和即时重放。
  3. 中等多台显示器刷新率不同时，拔掉副屏对比一局。
  4. 进阶问题仍在的话，用 DDU 在安全模式下彻底卸载后重装驱动。
  5. 进阶切换“硬件加速 GPU 计划”（设置 → 系统 → 显示 → 图形），重启后对比。

系统设置检查

与本次卡顿不一定直接相关，是同时检查出的系统设置问题。

优先处理

游戏安装在机械硬盘上（E 盘）

现代游戏大量依赖流式加载，机械硬盘是加载卡顿和贴图延迟的常见原因。

处理建议
  1. 中等把游戏迁移到 SSD（Steam、EA、Epic 都支持移动安装目录，无需重新下载）。
技术细节
WDC WD40EZAX-00C8UB0，MediaType = HDD
供参考

电源计划为“平衡”

多数情况下够用。如果分析中出现 CPU 降频或电源管理相关的原因，可以切换到高性能对比。

处理建议
  1. 简单在控制面板的电源选项中选择“高性能”，或在 Windows 11 的 设置 → 系统 → 电源 中把电源模式设为“最佳性能”。

F: 盘剩余空间不足（23GB）

SSD 剩余空间过少时写入性能会下降，影响该盘上游戏的加载。

处理建议
  1. 简单清理或迁移文件，保留 15% 以上空闲空间。
